### 司南评测模型性能分析
* 整体能力仍有较大提升空间
  * OpenCompass 采用了更加准确的循环评测策略对大模型能力进行分析。
* 在百分制的客观评测基准中 GPT-4o-20240513 也仅仅达到了 64 分的及格水平。
* 闭源大模型接近 GPT-4 水平
  * 近期发布的国产商业模型表现优异，多个维度上缩小了与 GPT-4 的差距
* 国内模型在中文场景具有性能优势
  * 在中文语言理解、中文知识和中文创作上，国内商业模型相比 GPT-4 具有极强的竞争力，甚至部分模型实现了单个维度上对 GPT-4 的超越。
* 开源社区未来可期
  * Lama3、Qwen1.5、Yi1.5、InterLM2 等等开源模型，展示出优秀的综合性对话体验，并接近商业闭源模型的性能,
* 复杂推理仍是短板
  * 国内多个模型综合能力和 GPT-4 在接近，但在复杂推理上仍然存在较大差距，并且和模型尺寸存在较强相关性。


### 发展趋势分析
* 模型尺寸逐渐收敛，大小模型并重
  * 面向端侧打造高推理速度、特定场景性能优异的 2B 参数以下的小模型
  * 云端服务集中以 70B - 100B 为主，具有性能与推理成本的较好平衡
  * 头部模型玩家的核心技术竞争集中千亿大模型，面向 AGI 持续探索涌现能力
* 稠密模型和 MoE 之争仍需探索
  * 模型宏观架构的路线探索尚未收敛
  * 稠密模型具有较好的推理效率，MoE 模型具有更强的性能潜力
* 长文本能力日益重要，基础结构多路线并行
  * 各类复杂应用场景对模型的长文本能力有较高要求
  * 高效注意力机制和 RNN 类模型，在超长文本建模上仍有发展潜力
* 复杂推理和智能体应用仍需技术突破
  * 现有的模型在多步复杂推理和各类交互式智能体应用中还有较大性能提升空间
  * 模型架构、合成数据策略、智能体系统设计等仍有大量技术难点亟需攻关
* 基于模型的评价将成为主流
  * 在专业知识领域，普通人类标注员的准确率可能相比先进大模型并无显著优势
  * 随着大模型能力的不断增强，使用模型对待测模型进行性能评估逐渐成为可能

## 使用 OpenCompass 评测 internlm2.5-chat-1.8b 模型在 ceval 数据集上的性能
### 环境及安装依赖
```shell
cd /root/opencompass
conda activate opencompass
conda install torch==2.1.2 pytorch==2.1.2 torchvision==0.16.2 torchaudio==2.1.2 pytorch-cuda=12.1 -c pytorch -c nvidia -y
apt-get update
apt-get install cmake
pip install protobuf==4.25.3
pip install huggingface-hub==0.23.2
```
    
  注意：这里需要 torch 也是 2.1.2 才能跑通


### 输出出所有跟 InternLM 及 C-Eval 相关的配置
```shell
python tools/list_configs.py internlm ceval
```


### 进行测评
```shell
 python run.py --datasets ceval_gen --models hf_internlm2_5_1_8b_chat --debug
```
 ![img_21.png](images/img_21.png)



### 使用配置文件来指定数据集和模型
```shell
python run.py configs/eval_tutorial_demo.py --debug 
```
