# 浦语提示词工程实践
## 提示工程
* 一种通过设计和调整输入( Prompts )来改善模型性能或控制其输出结果的技术。

### Prompt
- 为模型提供的输入，用以引导 AI 模型其生成特定的输出
- 大模型提示词是关键基础，应用最为广泛

### 提示词框架
#### CRISPE 框架
* Capacity and Role (能力与角色): 希望 InternLM 扮演怎样的角色
* Insight (洞察力): 背景信息和上下文(用 Context 更好)
* Statement (指令): 希望 InternLM 做什么
* Personality (个性): 希望 InternLM 以什么风格或方式回答你
* Experiment (尝试):要求 InternLM 提供多个答案

* 适合任务型

![img_11.png](images/img_11.png)


#### CO-STAR 框架
* Context (背景): 提供任务背景信息
* Objective (目标): 定义需要LLM执行的任务
* Style (风格): 指定希望LLM具备的写作风格
* Tone (语气): 设定LLM回复的情感基调
* Audience (观众): 表明回复的对象
* Response (回复): 提供回复格式

* 适合角色类，尤其是虚拟陪伴，需要构建大量角色的场景

### 构建高质量 Prompt 
* 细节法：给出更清晰的指令，包含更多具体的细节
* 分解法：将复杂的任务分解为更简单的子任务 （Let's think step by step, CoT，LangChain等思想）
* 记忆法：构建指令使模型时刻记住任务，确保不偏离任务解决路径（system 级 prompt）
* 解释法：让模型在回答之前进行解释，说明理由 （CoT 等方法）
* 投票法：让模型给出多个结果，然后使用模型选择最佳结果 （ToT 等方法）
* 示例法：提供一个或多个具体例子，提供输入输出示例 （one-shot, few-shot 等方法）


### 常用的提示词模块
* Attention：需重点强调的要点
* Background：提示词的需求背景
* Constraints：限制条件
* Command：用于定义大模型指令
* Definition：名词定义
* Example：提示词中的示例 few-shots
* Fail：处理失败时对应的兜底逻辑
* Goal：提示词要实现的目标
* Hack：防止被攻击的防护词
* In-depth：一步步思考，持续深入
* Job：需求任务描述
* Knowledge：知识库文件
* Lawful：合法合规，安全行驶的限制
* Memory：记忆关键信息，缓解模型遗忘问题
* Merge：是否使用多角色，最终合并投票输出结果
* Neglect：明确忽略哪些内容
* Odd：偶尔 （俏皮，愤怒，严肃） 一下
* OutputFormat：模型输出格式
* Pardon：当用户回复信息不详细时，持续追问
* Quote：引用知识库信息时，给出原文引用链接
* Role：大模型的角色设定
* RAG：外挂知识库
* Skills：擅长的技能项
* Tone：回复使用的语气风格
* Unsure：引入评判者视角，当判定低于阈值时，回复安全词
* Vaule：Prompt模仿人格的价值观
* Workflow：工作流程
* X-factor：用户使用本提示词最为重要的内核要素
* Yeow：提示词开场白设计
* Zig：无厘头式提示词，如[答案之书]

### 科幻小说生成
#### 未使用提示词
![img_26.png](images/img_26.png)


#### 使用提示词
提示词如下：
```markdown
您是未来世界的科幻小说家
- 技能：
- 📊 创造性思维、想象力、科幻元素理解
- 🚀 构建复杂世界观、创造独特角色、编写引人入胜的剧情
# 💬 输出要求：
- 结构化输出内容，包括完整的故事框架、角色设定、世界观构建等。
- 为故事提供**详细、准确和深入**的内容描述，确保故事连贯、逻辑严密。
- 生成的故事应具有高度的创意性和独特性，展现未来科技与人类社会的互动。
# 🔧 工作流程：
- 深入思考故事背景、主题和核心冲突。
- 逐步构建世界观，包括科技发展、社会结构、文化习俗等。
- 创造具有深度的角色，确保角色行为与动机一致。
- 编写故事大纲，包括起承转合的关键情节。
- 根据大纲详细编写故事，确保情节连贯、细节丰富。
# 🌱 初始化：
欢迎来到未来世界，这里充满了未知的科技与人类挑战。作为一位科幻小说家，您的任务是构建一个引人入胜的宇宙，创造独特的角色，并编写一个充满悬念和冲突的故事。现在，请开始您的创作之旅吧！
```
